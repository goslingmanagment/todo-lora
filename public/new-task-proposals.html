C1
Гайд-ссылка в пресете + нумерованные референсы. Самые дешёвые улучшения.

Что меняется:

  • Гайд-ссылка вшита в пресет (PPV / Photo set / Life-photo) — отображается pill-кнопкой рядом с описанием. Не дублируется в текст ТЗ.
  • Вложения с номерами — каждый референс показывает №1, №2… можно перетаскивать. Это формат брифов Дианы («1. Повторить, если позволяет гибкость», «2. Повторить, так же в чулках…»).
  • Описание-«рыба» очищено от ссылки на гайд и от «возьми идею из гайда» — это видно по pill-кнопке.

C2
Сдвоенный дедлайн для PPV / Photo set — отражает реальный шаблон «первый бандл, второй бандл».

Что меняется:

  • Для пресетов PPV-бандл и Photo set сайдбар показывает «Этап 1» и «Этап 2» вместо одного дедлайна — потому что в чате Диана всегда даёт два срока: «первый бандл до 22 мая, второй до 29».
  • Для остальных пресетов остаётся один дедлайн.
  • Кнопка + ещё этап позволяет включить второй дедлайн в любом другом типе.
  • Объём «5–15 фото / 5–10 мин» применим к каждому этапу, не суммарно — это уточнено в тексте.
Требует миграцию (добавить deadline_on_2 или таблицу milestones) — самое заметное улучшение workflow.

C3
Life-photo: структурированная заготовка из реальных подразделов Дианы.

Что меняется:

  • Для пресета Life-photo описание разворачивается в 5 коротких полей: Тип / Свет / Одежда / Подача / Сюжеты — это дословные подзаголовки из брифов Дианы.
  • Каждое поле — одна короткая строка, не блок текста. Заранее заполнено стандартом, можно дописывать «отличия».
  • Под полями — кнопка + свободный текст для всего нестандартного.
  • Без миграции: при сохранении 5 полей конкатенируются в обычный description. Это UI-надстройка над одним полем.
Осторожно: похожее уже пытались сделать (shot_list, миграция 0013) и откатили. Поэтому здесь — только для Life-photo, не для всех пресетов.

U1
Custom: имя для обращения в кадре + автоподсказка по повторным покупателям.

Что меняется:

  • «Имя для обращения в кадре» — отдельное поле под ником. В чате почти каждый custom-бриф содержит строку «Имя фана: Brandon / Marvel / Sam / Chris»; используется в репликах модели («hey Bob, do you like me Bob?»).
  • Автоподсказка по нику — повторные покупатели (arian_15 — 4 раза, jamesjamesjamesjames — 3, user863848546158272512 — 3). При вводе подтягивает платформу и имя.
  • Подсказка показывает количество предыдущих заказов (соц-доказательство, помогает узнать «фана-постоянника»).

Custom: свободная заметка к оплате под пресетами — для «100$ sub + 125$ tips» и подобных.

Что меняется:

# Изменение Приоритет Сложность Требует
C1a Гайд-линк в пресете (Notion URL зашит в CONTENT_TASK_PRESETS) ⚡ высокий низкая 2 строки в типе пресета, рендер в форме и в карточке задачи
C1b Нумерация вложений + drag-to-reorder высокий средняя уже есть sort_order в схеме — нужен только UI
C1c Пресет Instagram (новый шаблон в массиве) низкий низкая 1 объект в CONTENT_TASK_PRESETS
C2 Сдвоенные дедлайны для PPV / Photo set ⚡ высокий высокая миграция (deadline_on_2 или milestones), правки фида/карточки/индексов
C3 Структурные подполя Life-photo (без миграции, конкатенация) средний средняя условный рендер по пресету; помнить про откат shot_list в 0013
— Скрывать «Объём» для не-PPV/Photo set пресетов средний низкая 5 строк в сайдбаре
U1a Автоподсказка по buyer_handle (последние 10 уникальных) ⚡ высокий низкая server action + HTML <datalist>
U1b Поле «Имя для обращения в кадре» средний низкая переименовать placeholder у buyerDisplayName; либо новая колонка fan_name
U2 Свободная «Заметка по оплате» средний низкая колонка payment_note nullable

«⚡ высокий» — даёт заметный выигрыш на каждой задаче. C1a / U1a — почти бесплатные, делать в первую очередь.
